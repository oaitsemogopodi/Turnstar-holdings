# Turnstar data basis

Replaced the prior rental dataset and unused dataset-switching resource with a 12-component property registry and 60 new fictional sample units. Stable region, property and unit IDs are included in rental CSV. Each property includes region, sector and parentDevelopmentId. Every rental record has dataBasis: illustrative. Financial data lives separately in financial.js. User-supplied detailed consolidated FY2026 and FY2025 figures are used because the official report page could not be retrieved. No additional financial results are inferred.
